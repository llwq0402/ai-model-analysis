# AI模型性能与成本分析项目

一个基于真实数据的 AI 模型性能分析项目，重点研究不同模型在**性能、价格、速度**之间的权衡关系，并给出实际选型建议。

## 项目背景

随着大模型数量快速增长，不同厂商（如 OpenAI、Anthropic、Google 等）推出了大量模型版本。  
在实际应用中，如何在**性能、成本和响应速度之间做出合理选择**，成为一个重要问题。

本项目基于公开数据，对约 180 个 AI 模型进行系统分析，模拟真实业务中的模型选型决策过程。

## 数据说明

数据集包含以下字段：

- 模型名称（Model）
- 所属厂商（Creator）
- Intelligence Index（模型性能指标）
- 价格（USD / 百万 tokens）
- 生成速度（tokens/s）
- 延迟（首 token 响应时间）

## 数据处理

在分析前对数据进行了清洗与预处理：

- 清洗 `intelligence_index` 中的非数值字符（如等级标记 E）
- 将价格字段从字符串转换为数值类型
- 将价格为 0 的模型单独处理（避免性价比计算出现无穷大）
- 删除异常值和缺失值（如 speed=0）

## 分析流程

本项目按照完整数据分析流程展开：

1. 数据读取与清洗  
2. 数据分布分析（EDA）  
3. 模型性能排名分析  
4. 价格与性能关系分析  
5. 速度与性能关系分析  
6. 性价比分析  
7. 免费模型与付费模型对比  
8. 厂商维度分析  
9. 综合评分模型构建  

## 核心分析结果

### 1. 模型性能格局：头部集中明显

高性能模型主要集中在少数厂商：

- OpenAI
- Anthropic
- Google

结论：当前 AI 模型市场呈现明显的“头部集中”特征。

### 2. 价格与性能：中等相关，但非线性

- 相关系数约为 **0.53**

对比例如：
- Claude Opus 4.5：高价但优势有限  
- Gemini 3 Flash：低价但性能接近头部

结论：价格越高通常性能越好，但存在大量高性价比模型。

### 3. 性能差距缩小，价格差距较大

头部模型之间性能差距通常只有 2–5 分  
但价格差异可达数倍

结论：模型选型已从“性能优先”转向“成本效率优先”

### 4. 速度与性能：几乎无明显关系

- 相关系数约为 **0.10**

结论：高性能模型不一定更慢，部分模型（如 Gemini Flash）同时具备高性能和高速度。

### 5. 性价比分析

性价比最高的模型包括：

- MiMo-V2-Flash  
- gpt-oss-20B  
- NVIDIA Nemotron 系列  

结论：最适合大规模部署的模型 ≠ 性能最强模型

### 6. 厂商对比分析

- OpenAI：单模型性能最强 + 产品线最完整  
- Anthropic：平均性能最高（整体稳定性强）  
- Google：性能、价格、速度平衡较好  
- 其他厂商：在性价比方向表现突出  

## 最终结论

在实际应用中，应根据业务场景进行选择：

- 高复杂任务 → 选择高性能模型  
- 成本敏感场景 → 选择高性价比模型  
- 实时系统 → 选择高速度模型
